# 习惯数据模型

每个习惯有 id、name、weekdays、color、createdAt 和 logs 六个字段。normalizeHabit 校验后返回一个新对象，移除未知字段，并复制、排序星期与日志数组。

| 字段 | 规则 |
| --- | --- |
| id | 非空字符串，最多 100 个 JavaScript 字符单元 |
| name | 去掉首尾空白后 1–80 个字符单元 |
| weekdays | 1–7 个不重复的整数；0 是星期日，1 是星期一，6 是星期六 |
| color | green、blue、amber 或 rose，其他值归为 green |
| createdAt | 真实存在的 YYYY-MM-DD 日期 |
| logs | 最多 20,000 个唯一日期，不能早于 createdAt，必须符合 weekday 计划 |

例如 weekdays: [1, 3, 5] 表示周一、周三、周五。计划排序后按数字 0–6 存储，这与界面日历采用周一作为第一列是两个不同约定。

日志是某个日期是否完成的记录，没有每次打卡的时刻或次数；同一天重复记录会被拒绝。原始记录规范化不使用系统当前时间，因此未来日期的限制由导入或打卡操作在得到参考日期后检查。

字符上限按字符串 length 计算，emoji 可能占两个字符单元。日期采用四位年份；跨过年份 0000 或 9999 的偏移会报错。业务函数不读取 DOM 或浏览器存储，适合传入固定日期独立测试。
