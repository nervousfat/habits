# 备份与恢复

备份是 UTF-8 JSON，根对象包含 app: little-habits、version: 1 和 habits 数组。空备份：

~~~json
{"app":"little-habits","version":1,"habits":[]}
~~~

习惯字段见 [数据模型](data-model.md)。一个备份最多 100 个习惯，ID 不可重复。导入会规范化记录、剥离未知字段，并拒绝晚于参考日期的创建日和打卡日。

导入文本和导出的标准格式文本都最多 5,000,000 个 UTF-8 字节。大小包含标点、空白和缩进；中文和 emoji 不能按字符串 length 估算字节数。即使紧凑输入低于上限，标准化后的备份超过上限也会被拒绝，保证接受的数据可以重新导出。成功导出的历史记录在相同或更晚的参考日期可以再次导入。

浏览器中的导入会先完整验证，再请求替换当前记录；它不会按 ID 合并。因此先导出目标数据，再选择来源文件，确认习惯数量后进行替换。无效 JSON、重复 ID、休息日打卡或超限文件不会被部分应用。

localStorage 只属于当前浏览器和网站来源。不同端口、127.0.0.1 与 localhost、隐私窗口及另一台电脑都不会自动同步记录。迁移时导出文件，再到新来源导入。

若存储被禁用或配额已满，先保留可导出的备份并处理浏览器存储问题。无法读取的原始记录可通过页面恢复操作清除，但该清除不能撤销；不要把清理作为首个排查步骤。保留原备份副本，再在副本上修正字段。
